# 独立架构

React UI → 仅监听回环地址的 FastAPI 服务 → 用户配置的 OpenAI-compatible API。

provider_config.py 保存非秘密配置与 DPAPI 密文，保存地址改变时不复用旧 Key。open_ai.py 实现文本/图片请求、图示自动选型、图库数量版本、图表数据生成、封面策划和 SVG 校验。app.py 只保留配置、校验、AI 操作及 WPS 本机启动桥接；没有登录、项目、网站同步和云存储接口。

prompts 中移植了封面策划/风格/标题、图表、复杂图示、简单图示选型与母版适配契约。简单图示保留按关系选择、同结构样式组、支持节点数和匹配数量的 SVG 母版规则。实际文本模型与图片模型均来自用户配置，不继承项目中的模型路由或密钥。

原生 Office/WPS 组件负责功能区、WebView2 窗口、SVG/图片/封面插入和既有对象工具。编译与安装均使用独立产品标识，避免覆盖商业版注册。
