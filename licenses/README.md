# Third-party components

Project code and migrated SANDUN prompts are Apache-2.0. Dependencies retain their original terms; full notices are included here. DEPENDENCIES.json records the tested build versions.

Microsoft WebView2 SDK 1.0.2365.46 is distributed under its included Microsoft license and notices. A separately installed WebView2 Runtime is required. Microsoft Office/WPS are not bundled. Extensibility.dll is the Microsoft Office extensibility interop assembly; it defines the COM interface and is required to load the native add-in. It is not covered by the project Apache license.

The installer is built with Inno Setup; its license is included as InnoSetup-LICENSE.txt. The frozen Python runtime is redistributed under the Python Software Foundation license in Python-LICENSE.txt. PyInstaller-COPYING.txt includes the bootloader exception permitting distribution of the resulting executable under the project's license.
